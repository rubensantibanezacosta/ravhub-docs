## Current status

- `RavHub Enterprise` is not publicly released yet
- there is no public image currently available for Bare Docker deployment
- the current public Beta is focused on `RavHub Core`

## What this means

- if you want to try RavHub today, the available deployment path is `RavHub Core`
- Enterprise still appears in the docs so you can understand its planned scope and current status
- when Enterprise is published, this page will be replaced with the actual deployment guide

## What is planned for Enterprise

- license-based activation
- advanced storage backends such as `s3`, `gcs`, and `azure`
- a deployment path for installations that need advanced capabilities

## What to do today

- use [Core · Bare Docker](./core-bare-docker) if you want to deploy RavHub now
- use [Core · Helm Chart](./core-helm-chart) if you prefer Kubernetes
- read [Core vs Enterprise](../product/core-vs-enterprise) to understand the difference in current availability

Continue with [Core · Bare Docker](./core-bare-docker) or review [Enterprise · Helm Chart](./enterprise-helm-chart) for the same status on Kubernetes.
