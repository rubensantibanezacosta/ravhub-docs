## Main features

- Support for `hosted`, `proxy`, and `group` repository types
- Web UI to browse repositories, packages, and versions
- Client command generation from the UI itself
- Deployment of `RavHub Core` through Docker or Kubernetes with Helm Chart
- Persistent artifact storage
- Basic instance health validation

## Current Beta status

- The current public Beta is focused on `RavHub Core`
- `RavHub Enterprise` is not publicly released yet
- Public documentation still references Enterprise to explain its planned scope and current status

## Ecosystems and clients

The public documentation currently covers these clients:

- NPM / pnpm
- Maven / Gradle
- PyPI / pip / twine
- NuGet
- Composer
- Cargo
- Docker
- Helm

## Deployment-focused features

- Bare Docker installation
- Helm Chart installation
- Core edition
- Enterprise status and planned scope
