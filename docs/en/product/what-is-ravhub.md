## What RavHub is

RavHub is a platform to manage package and artifact repositories on infrastructure you control.

It helps teams centralize package publishing and consumption across multiple ecosystems without depending on an external managed service.

## What problem it solves

- Centralizes internal repositories
- Supports private package distribution
- Adds proxy repositories in front of upstream registries
- Groups repositories behind a single consumer endpoint
- Provides a web UI to browse packages, versions, and client commands

## What you can do with RavHub

- Publish internal packages
- Consume packages from standard clients
- Place a proxy in front of external registries
- Expose a single endpoint per format or group

## Repository types

- `hosted` for your own content
- `proxy` to cache or route to external registries
- `group` to combine several repositories behind a single consumption URL
