## Current policy

- The root English locale under `/en/` is the current maintained entry point.
- The route `/0.1.0/` stores the Spanish documentation for release `0.1.0`.
- The route `/en/0.1.0/` provides an English entry page for that same release.

## Available versions

- [Current](/en/)
- [0.1.0](/en/0.1.0/)

## When to use each one

### Use `Current`

- if you are evaluating RavHub now
- if you want the actively maintained documentation entry point

### Use `0.1.0`

- if you are operating exactly on that release
- if you need to review the Spanish documentation for `0.1.0`

## Next step

Open [0.1.0](/en/0.1.0/) or go back to the [current English home](/en/).
