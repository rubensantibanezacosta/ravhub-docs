## Qué es RavHub

RavHub es una plataforma para gestionar repositorios de artefactos y paquetes desde tu propia infraestructura.

Permite centralizar publicación y consumo de paquetes en varios ecosistemas sin depender de un servicio gestionado externo.

## Qué problema resuelve

- Centraliza repositorios internos
- Permite crear repositorios privados
- Permite usar proxies hacia registros upstream
- Permite agrupar repositorios bajo un único endpoint
- Da una interfaz web para navegar paquetes, versiones y comandos de cliente

## Qué puedes hacer con RavHub

- Publicar paquetes internos
- Consumir paquetes desde clientes estándar
- Poner un proxy delante de registros externos
- Exponer un endpoint único por formato o grupo

## Tipos de repositorio

- `hosted` para contenido propio
- `proxy` para cachear o enrutar hacia registros externos
- `group` para combinar varios repositorios en una sola URL de consumo
