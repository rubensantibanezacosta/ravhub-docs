## Política actual

- La raíz `/` representa la documentación estable actual.
- La ruta `/0.1.0/` contiene la documentación de la versión `0.1.0`.
- Las nuevas versiones podrán publicarse con el mismo patrón cuando existan cambios de producto o despliegue.

## Versiones disponibles

- [Actual](/)
- [0.1.0](/0.1.0/)

## Cuándo usar cada una

### Usa `Actual`

- si estás evaluando RavHub ahora
- si quieres la documentación mantenida como referencia principal

### Usa `0.1.0`

- si operas exactamente sobre esa release
- si necesitas revisar imágenes, ejemplos o despliegues congelados en `0.1.0`

## Siguiente paso

Si ya sabes qué versión necesitas, entra en [0.1.0](/0.1.0/) o vuelve a la [documentación actual](/).
